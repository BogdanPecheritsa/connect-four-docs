## Запуск проєкту
Для роботи необхідна Node.js.

Команди:
- `npm install` — встановлення залежностей.
- `npm start` — запуск локального сервера.
- `npm run build` — збірка продакшн версії.
- `npm run docs` — генерація технічної документації.
